# Assignment 6 - Visitor Pattern

## Description
A simple file system using Visitor Pattern in Java.

## Features
- Calculate total file size
- Search files by name and size
- Count files and directories
- Calculate maximum depth
- Validate file system structure

## Technologies
- Java 17
- Maven
- JUnit 5

## Run
Run Main.java in IntelliJ IDEA.

## Tests
mvn clean test

8 JUnit tests passed.
